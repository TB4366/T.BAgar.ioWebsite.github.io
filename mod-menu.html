Agar.io Private Server

1

Install Sing-box

Install Sing-box Open Sing-box on the App Store ↗
2

Open your iPhone Settings

Go to: Settings → General → VPN & Device Management → Profile Download
3

Install your Agar.io mod

Install your Agar.io mod from this website. Open T.B Agar.io Mod Menu ↗
4

Open Sing-box and create a profile

Open the Sing-box app and go to Dashboard.

Under Dashboard, open Profile.

Press the + button in the top-right corner.

Select New Profile.

Press the bottom button Create Manually.

Press Name and enter a name, for example: Agar.io Private Server.

Press Create.
5

Add the server script

Press the + button again.

Tap Edit Content.

Open Script at the bottom.

Copy the script below and paste it into the Sing-box app.
6

Turn on the VPN

Press the Play button in the bottom-right corner of your screen.

When the VPN is active, open Agar.io.

You may need to wait a little while before the server appears.
7

Copy the server script

When the server appears, press the Script button.

You will see the script.

Press Copy to copy it.

Press the × in the top-right corner to return to the steps.
8

Close the instructions

The × in the top-right corner next to T.B Agar.io closes the instructions.

Press it when you are finished.

Questions or need help?

Need help with something? Feel free to contact T.B Agar.io. You can contact us using the buttons below.
