🔧 Facebook Login Setup

Volg deze stappen om Facebook Login in te schakelen:

Stap 1: Facebook App Aanmaken

  1. Ga naar developers.facebook.com
  2. Klik op "My Apps" → "Create App"
  3. Kies "Consumer" als app type
  4. Vul app details in en maak aan

Stap 2: App ID Kopieëren

  1. In je app dashboard, ga naar Settings → Basic
  2. Kopieer je App ID
  3. Plak hieronder en klik "Opslaan"

Stap 3: Facebook Login Product Toevoegen

  1. In je app, ga naar Products
  2. Zoek "Facebook Login" en klik "Set Up"
  3. Kies "Web" als platform
  4. Voeg je website URL toe in Settings → Basic (Valid OAuth Redirect URIs)
